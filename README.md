## ✨ 주요 제공 기능 (Key Features)

### 1. 100% 안정적인 순정 React 댓글 위젯
* **네트워크 fetch() 0회**: 외부 AJAX 비동기 네트워크 요청을 완전 배제하여, Kakao/Tistory의 순정 React 댓글 시스템 세션 인증 및 렌더링 절차와 100% 무결하게 공존합니다. 댓글창이 굳거나 unmount되는 크래시 현상을 원천 방지했습니다.

### 2. 사이드바 최근글 재활용을 통한 "최신글 더보기"
* **안전한 스크래핑**: 상세 본문 페이지 하단에 중첩된 Tistory 치환자 루프를 배치하지 않고, 이미 사이드바에 렌더링된 최근글 정보를 로컬 DOM에서 순수하게 복제 및 조합하여 0ms만에 최근글 리스트를 화면에 렌더링합니다.

### 3. 지연식 썸네일 수분 공급 (Dual-Phase Hydration)
* **회색 스켈레톤 대기 (3.2초 이내)**: 썸네일 이미지의 존재 유무가 확정되기 이전에는 눈에 피로를 주는 임시 원색 그라데이션이 전혀 표시되지 않으며, 차분한 회색 기본 뼈대(Skeleton)로 대기하여 시각적 일관성을 확보하고 CLS(누적 레이아웃 이동)를 0%로 통제합니다.
* **이미지-그라데이션 완벽 분기 (3.2초 이후)**: 댓글 위젯 로드가 완전히 끝나 브라우저가 평온해진 3.2초 뒤, 백그라운드 채집을 통해 **진짜 썸네일 사진이 있는 포스트는 실제 사진**으로 부드럽게 스왑하고, **진짜 사진이 없는 포스트만 Toss Tech 스타일 HSL 그라데이션과 이니셜 배지**를 채워줍니다.
* **초고속 세션 캐싱**: 한 번 방문해 구축된 썸네일 정보는 `sessionStorage` 로컬 캐시에 보관되어, 다음 방문부터는 3.2초 대기 없이 **접속 즉시 0ms만에 실제 썸네일 사진이 즉각 노출**됩니다.

### 4. 대댓글 멘션 태그 무손실 마크다운 파서
* **멘션 격리 추출 알고리즘**: 대댓글 작성 시 삽입되는 멘션 태그(`<em class="tt-txt-mention">@닉네임</em>`)를 마크다운 컴파일 직전에 **사전 분리 및 격리**시킵니다.
* **답글 내 자유로운 마크다운**: 멘션이 제외된 본문 텍스트에만 마크다운 번역(`marked.parse`)을 돌린 후 첫 단락(`<p>`) 내부에 원래의 멘션 태그를 온전한 기능과 배지 스타일 그대로 다시 결합합니다. 대댓글 멘션 배지 뒷부분에 자유롭게 엔터(`\n`)를 쳐서 `# 제목` 이나 코드블록 등을 적어도 깨짐 없이 완벽하게 변환됩니다.

### 5. PC-모바일 반응형 유동 폰트 크기 보정 (Fluid Comment Sizing)
* **데스크톱 (PC) 환경**: 본문 글 크기(16px)보다 아담하고 조밀하게 정돈되도록 댓글 영역 전체 폰트(본문, 목록, 문단 등)를 **`14px`**로 일괄 컴팩트화했습니다.
* **모바일 (Mobile) 환경**: 화면이 작아 눈이 피로해지는 모바일 뷰포트에서는 가독성 및 모바일 본문 밀도와 조화롭게 맞춰지도록 **`15px`**로 유동적으로 자동 리사이징 확대됩니다.

### 6. 모바일 탑바 슬림화 및 콤팩트 스케일화
* **헤더 공간 최적화**: 모바일의 세로 높이를 시원하게 확보하도록 탑바의 세로 두께를 기존 `60px`에서 **`48px`**로 슬림하게 리사이징했습니다. 로고 폰트 크기는 **`17px`**로 엣지 있게 조율했습니다.
* **검색바 가로 폭 잠금**: 모바일에서 화면 절반 이상을 뚱뚱하게 덮어버리던 검색창의 너비를 **`120px`**로 아담하게 고정하고 뱃지를 숨겨, 테마 및 메뉴 버튼들과 함께 가로 1열로 세련되게 모바일 헤더에 정렬되도록 비율을 다듬었습니다.

### 7. iOS Focus Zoom 100% 원천 방지 및 기하학적 스케일 보정
* **모바일 입력창 포커스 줌 제거**: 모바일 화면에서 검색창 및 댓글/방명록 입력칸 터치 시 모바일 브라우저가 화면을 강제로 줌인시키는 현상을 막기 위해, 사이트 전역의 모든 모바일 인풋/텍스트에어리어에 **`font-size: 16px !important`**를 강제 적용해 확대 조건을 차단했습니다.
* **수학적 스케일 보정**: 글자 폰트가 투박하게 커 보이지 않도록 시각적 크기는 **14px 비주얼(`transform: scale(0.875)`)**로 세련되게 축소하고, 스케일 수축으로 인해 테두리 여백이 남거나 어긋나지 않도록 가로 너비를 수학적으로 정확히 연산된 **`114.28%`**(`100 / 0.875 = 114.28%`)로 보정하는 고급 기하학 CSS를 적용했습니다.

### 8. 블로거 닉네임 로고 (`[##_blogger_##]`) 동적 브랜딩
* 사이드바 최상단 및 상단 고정 탑바의 브랜드 로고 텍스트를 단순 블로그 제목 대신 블로거 본인의 고유 닉네임 공식 치환자인 **`[##_blogger_##]`**로 동적 연동하여, 나만의 개성이 드러나는 퍼스널 브랜딩 블로그를 제공합니다.

## 🛠️ 스킨 등록하기

처음 한 번만 등록하면 됩니다.

1. `tistory-skin-toss-tech.zip` 압축을 풉니다.
2. 티스토리 관리자 → **꾸미기 > 스킨 변경 > 스킨 등록**으로 이동합니다.
3. **추가** 버튼을 눌러 압축 해제한 파일을 모두 업로드합니다.
   - `skin.html`, `style.css`, `index.xml`, `script.js`, `preview.gif`, `preview256.jpg`, `preview560.jpg`
   - ZIP은 하위 폴더 없이 1단계 flat 구조로 배포됩니다.
4. 티스토리는 업로드한 보조 파일을 스킨 내부 이미지 경로로 관리하므로 `script.js`는 `skin.html`의 `./images/script.js` 참조와 연결됩니다.
5. **저장** 버튼을 누르고 스킨 이름을 입력합니다.
6. **스킨 변경 > 스킨 보관함**에서 등록한 스킨을 선택하고 **적용**을 누릅니다.

## 💻 로컬에서 개발하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드 (dist/tistory-skin-toss-tech.zip 압축파일 자동 래핑 생성)
npm run build

# 티스토리 치환자/댓글 fixture 기반 로컬 Playwright 스모크 테스트 가동
npm run test:local
```

빌드가 완료되면 `dist/tistory-skin-toss-tech.zip` 파일이 자동으로 무결하게 생성됩니다.
로컬 검증은 `dev/article.html`, `dev/list.html` 및 `dev/skin.html`을 자동 렌더링한 뒤 댓글 폼, 대댓글 멘션 격리 마크다운 파싱, 답글 트리거, 목차, 모바일 스케일, 사이드바 스크래핑 최근글 그라데이션 플레이스홀더를 Playwright로 정교하게 확인합니다.
