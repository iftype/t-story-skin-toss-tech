# 토스 테크 스타일 티스토리 스킨

티스토리 블로그를 [토스 테크](https://toss.tech) 블로그처럼 보이게 만드는 스킨입니다.
글 쓰는 방법에 몇 가지 규칙을 두면 홈 카드 미리보기, 코드 블록 제목 같은 기능을 쓸 수 있습니다.

---

## 📦 스킨 다운로드

### [📦 최신 버전 다운로드](https://github.com/iftype/t-story-skin-toss-tech/releases/latest/download/tistory-skin-toss-tech.zip)

직접 빌드했다면 `dist/tistory-skin-toss-tech.zip`을 쓰면 됩니다.

---

## ✍️ 글 쓰는 규칙

### 홈 카드·슬라이더 미리보기 = 글 맨 위 인용문

홈의 글 카드와 슬라이더에 보이는 요약은 **첫 번째 소제목(제목 2·3) 앞에 쓴 글**에서 가져옵니다.
글 맨 위에 인용문을 하나 두고, 그 아래에 소제목을 시작하면 그 인용문이 미리보기가 됩니다.

- 인용구 스타일은 상관없지만 **인용구 3(둥근 회색 상자)** 을 권장합니다. 본문에서도 요약 상자처럼 보입니다.
- 첫 소제목 앞에 아무것도 없으면 `들어가며` / `시작하며` / `소개` / `Intro` 소제목 아래 문단을, 그것도 없으면 첫 소제목 아래 문단을 씁니다.
- 최대 220자까지 보입니다.

```
[인용구 3] 네트워크 응답이 빨리 오면 로딩 UI가 생기자마자 사라지며 화면이 깜빡여요.   ← 미리보기
[제목 2] 들어가며
본문...
```

### 홈 카드·슬라이더 이미지 = 대표이미지

글쓰기 화면에서 지정한 **대표이미지**가 홈 카드와 슬라이더에 쓰입니다.
대표이미지가 없으면 제목으로 만든 색 그라데이션이 대신 들어갑니다. GIF도 끝까지 재생됩니다.

### 코드 블록 제목 = 첫 줄 주석

코드 블록 **첫 줄에 주석**을 쓰면 그 줄은 화면에서 지워지고 코드 블록 위 제목이 됩니다.

| 첫 줄 | 색(하이라이팅) | 위 제목 |
|---|---|---|
| `// useDelayedLoading.tsx` | 확장자 기준 (`.tsx`) | `useDelayedLoading.tsx` |
| `# scripts/deploy.sh` | `.sh` → bash | `scripts/deploy.sh` |
| `// bash` | bash | `BASH` |
| (주석 없음) | 에디터에서 고른 언어 | 제목 없음 |

- 주석 기호는 `//`, `#`, `--` 중 하나면 됩니다. 폴더 경로도 됩니다.
- 하이라이팅되는 확장자: `ts` `tsx` `js` `jsx` `mjs` `py` `sh` `yml` `md` `html` `css` `json` `java` `kt` `sql`
- 모르는 확장자나 `// todo 나중에 고치기` 같은 일반 주석은 건드리지 않고 코드에 그대로 둡니다.

### 인라인 코드 = 백틱

본문에서 `` `useDelayedLoading` ``처럼 백틱 한 쌍으로 감싸면 회색 인라인 코드로 보입니다.
(티스토리 기본 에디터는 마크다운 모드가 아니면 백틱을 그대로 두지만, 이 스킨이 바꿔서 보여 줍니다.)
코드 블록 안의 백틱과 짝이 없는 백틱은 그대로 둡니다.

### 인용구 스타일

| 에디터 스타일 | 보이는 모양 |
|---|---|
| 인용구 1 | 큰 따옴표(“) 아래 가운데 정렬 |
| 인용구 2 | 왼쪽 파란 선 + 연한 배경 상자 |
| 인용구 3 | 둥근 회색 상자 (미리보기용 추천) |

### 카테고리 = 폴더, 글 = 파일

사이드바와 `/category` 페이지의 카테고리는 폴더 트리로 보입니다.
카테고리를 누르면 펼쳐지고, 그 안에 글 목록이 파일처럼 들어 있습니다. 지금 보고 있는 글은 강조되고 그 폴더는 펼쳐집니다.

## ✨ 그 밖의 기능

- **이미지 확대**: 본문 이미지를 누르면 같은 이미지가 화면 가운데에 살짝 크게(최대 1.4배) 뜹니다. 빈 곳·이미지·Esc를 누르거나 스크롤하면 닫힙니다. 모바일은 확대하지 않습니다.
- **표**: 모바일에서 열이 많은 표는 옆으로 밀어 볼 수 있고, 짧은 칸은 줄바꿈하지 않습니다.
- **홈 슬라이더**: 최근 글을 7초마다 넘깁니다. 화살표로 넘기면 시간이 처음부터 다시 셉니다.
- **다크 모드**: 처음 온 사람은 라이트 모드로 시작합니다. 테마 버튼을 직접 누른 경우만 그 선택을 기억합니다.
- **상단바**: 블로그 주인에게는 `관리 · 글쓰기`(글 페이지에서는 `수정 · 삭제`도), 방문자에게는 `구독하기`가 보입니다. 모바일에서 구독하기는 햄버거 메뉴 안에 있습니다.
- **비밀번호 보호글**: 자물쇠 카드와 비밀번호 입력칸을 보여 줍니다.
- **공감(하트)**: 데스크톱 글 화면 왼쪽에 떠 있고, 글 아래에도 있습니다.
- **댓글**: 토스 테크처럼 둥근 입력칸과 `댓글 남기기` 버튼. 댓글 본문의 마크다운을 렌더링합니다.
- **본문 글자 크기**: 데스크톱 약 16px, 모바일 13.5px.

## ⚙️ 내 블로그에 맞게 설정하기

개인 정보는 코드에 없고 `skin.config.json` 한 곳에 모여 있습니다. 기본값은 모두 빈칸입니다.

```json
{
  "skin": {
    "name": "Toss Tech Style",
    "description": "스킨 보관함에 보이는 설명"
  },
  "owner": {
    "github": "https://github.com/내아이디",
    "email": "me@example.com",
    "linkedin": "https://www.linkedin.com/in/내아이디"
  }
}
```

| 항목 | 쓰이는 곳 | 빈칸이면 |
|---|---|---|
| `skin.name`, `skin.description` | 스킨 보관함의 이름·설명 | 기본 이름 |
| `owner.github` | 푸터 GitHub 아이콘 | 아이콘 숨김 |
| `owner.linkedin` | 푸터 LinkedIn 아이콘 | 아이콘 숨김 |
| `owner.email` | 푸터 메일 아이콘 (`mailto:`) | 아이콘 숨김 |

채운 뒤 `npm run build` 하면 `dist/index.xml`의 스킨 옵션 기본값에 들어갑니다. 버전은 `package.json`의 `version`을 따릅니다.

빌드하지 않고 받은 zip을 그대로 쓴다면, 스킨을 적용한 뒤 **꾸미기 > 스킨 편집 > 스킨 옵션**에서 `프로필 GitHub URL` 같은 칸을 채워도 됩니다. 이미 적용된 스킨은 스킨 옵션 값이 우선합니다.

## 🛠️ 스킨 등록하기

처음 한 번만 등록하면 됩니다.

1. `tistory-skin-toss-tech.zip` 압축을 풉니다.
2. 티스토리 관리자 → **꾸미기 > 스킨 변경 > 스킨 등록**으로 이동합니다.
3. **추가** 버튼을 눌러 압축 해제한 파일을 모두 업로드합니다.
   - `skin.html`, `style.css`, `index.xml`, `script.js`, `preview.gif`, `preview256.jpg`, `preview560.jpg`
   - `script.js`는 티스토리가 `images/script.js` 경로로 저장하고, `skin.html`이 그 경로를 불러옵니다.
4. **저장** 버튼을 누르고 스킨 이름을 입력합니다.
5. **스킨 변경 > 스킨 보관함**에서 등록한 스킨을 선택하고 **적용**을 누릅니다.

이미 적용한 스킨을 고칠 때는 **꾸미기 > 스킨 편집**에서 `skin.html` / `style.css`를 바꾸고, 파일 업로드에서 `script.js`를 다시 올리면 됩니다(스킨 설정이 유지되고 보관함이 늘지 않습니다).

## 💻 로컬에서 개발하기

```bash
npm install
npm run dev          # 개발 서버
npm run build        # dist/ 와 dist/tistory-skin-toss-tech.zip 생성
npm run test:local   # 티스토리 치환자 fixture 기반 Playwright 스모크 테스트
```

| 폴더 | 내용 |
|---|---|
| `public/skin.html` | 티스토리 치환자가 들어간 스킨 HTML |
| `src/*.js` | 스킨 동작 (`main.js`가 진입점) |
| `src/styles/` | 스타일 |
| `src/highlight/` | 코드 하이라이터 (Prism을 스킨에 직접 포함) |
| `skin.config.json` | 블로그 주인 정보·스킨 이름 (빌드할 때 `index.xml`에 들어감) |
